# Installer license bundle

The installer copies the project `LICENSE` and `THIRD_PARTY_NOTICES.md` into its `licenses` directory. Runtime archives may also contain component-specific license files.

This directory is intentionally incomplete for `1.0.0-rc.1`: CUDA, WebView2, Microsoft runtime, dependency, model-conversion and corpus redistribution reviews remain release blockers. Add the authoritative license texts and notices here only after review; do not treat this placeholder as public-distribution approval.
