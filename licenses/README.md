# Installer license bundle

The installer copies the project `LICENSE` and `THIRD_PARTY_NOTICES.md` into its `licenses` directory. Runtime archives may also contain component-specific license files.

This directory is maintained with each release. CUDA, WebView2, Microsoft runtime, dependency, model-conversion and corpus notices are recorded in `THIRD_PARTY_NOTICES.md`; add authoritative license texts when updated materials require them.
