# ILIA 1.1.10 发布说明

ILIA 1.1.10 是 1.1.9 的恢复流程完善版，包含 1.1.9 的正式构建修复和设置页面重构，并确保恢复完成后以正常可见窗口启动应用。

## 修复与改进

- 正式桌面程序只加载内置 `http://tauri.localhost/` 资源，不再依赖开发服务器 `127.0.0.1:1420`。
- 发布脚本在签名打包前强制执行 Tauri 正式构建，阻止开发构建产物进入更新包。
- 本地更新包始终在安装盘内暂存，支持更新文件和安装目录位于不同磁盘。
- 恢复安装程序自动查找现有 ILIA 安装，重建桌面和开始菜单快捷方式。
- 恢复完成后由安装程序显式以正常窗口启动 ILIA，不再继承隐藏启动状态。
- 设置页按“性能与资源、更新来源与离线安装、备份与恢复”重新组织。

## 升级说明

- 1.1.5—1.1.7 和 1.1.9 可通过应用内更新升级至 1.1.10。
- 1.1.8 更新后出现 `ERR_CONNECTION_REFUSED` 的用户，请直接运行 `ILIA-1.1.10-windows-x64-recovery.exe`。
- 本版仅替换应用和更新器，不重新下载模型、资料库或完整离线安装分卷。
