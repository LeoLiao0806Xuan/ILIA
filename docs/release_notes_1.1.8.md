# ILIA 1.1.8 发布说明

ILIA 1.1.8 是教程与更新体验的小型成品化修订，移除了容易被误认为错误提示的红色圆形热点，并补齐本地更新选择、更新预览和下载取消能力。

## 本次改进

- 六个教程步骤不再显示高饱和红色圆点。
- 教程示意改为带真实控件、文本和工作区层级的界面缩略图，不再使用灰色骨架占位图。
- 当前教学区域以低饱和金色描边显示，不再使用悬浮圆点或重复编号。
- 本地更新支持系统文件选择器和拖放 `.ilia` 文件，不再要求手动输入路径。
- 在线及本地更新在安装前显示当前版本、目标版本、来源、组件和下载体积。
- 更新下载可主动取消；取消后当前版本不变，已下载片段保留供续传。
- 更新进度增加实时速度和预计剩余时间。

## 更新方式

- 1.1.5—1.1.7 可通过已签名的应用内更新升级到 1.1.8。
- GitHub 不可达时，可下载并导入 `ILIA-1.1.8-offline-update.ilia`。
- 本版按补丁版本策略只发布约 51 MB 的应用更新，不重新制作约 4.3 GB 的完整离线安装分卷。首次安装可先使用 1.1.7 完整离线安装包，再升级到 1.1.8。

## 安全说明

- 更新包仍执行 Ed25519 签名和 SHA-256 校验。
- 本次不变更本地模型、资料库、研究项目或用户数据。
