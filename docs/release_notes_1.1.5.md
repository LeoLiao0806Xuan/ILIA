# ILIA 1.1.5 发布说明

ILIA 1.1.5 是 1.1 系列的易用性、项目工作区和弱网络更新改进版本。

## 更低的使用门槛

- 新增常驻“使用指南”入口，以六个步骤解释提问、研究模式、案件/项目、证据核验、资料库、导出与更新。
- 首次使用显示可关闭的新手提示；研究模式会直接说明适用场景，并提示 `Ctrl + Enter` 快捷操作。
- 左侧研究起点现在会填入完整、可直接运行的问题，而不是只有主题短语。

## 项目工作区

- 项目窗口改为“左侧创建、右侧工作”的双栏结构，当前项目与研究笔记成为视觉主区。
- 笔记编辑区域扩大，自动保存状态、项目说明和标签始终可见。
- Markdown 与自包含 HTML 导出集中到统一操作栏，并说明各自用途。

## 弱网络更新

- 更新清单请求遇到临时网络错误会自动重试。
- 更新负载遇到 DNS、超时、连接重置、断流等问题时最多自动重试五次，并从已下载位置续传。
- 下载失败后 ILIA 保持打开，原版本不被替换；进度窗口提供“重新连接并续传”。
- 设置页明确展示代理和本地签名 `.ilia` 更新包两种长期不可达兜底路径。

## 兼容性

- 支持从 1.1.0 至 1.1.4 直接更新。
- 核心资料库、模型、推理运行时与可写数据库架构均未变化。
