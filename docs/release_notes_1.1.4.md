# ILIA 1.1.4 发布说明

ILIA 1.1.4 是 1.1 系列的界面、数据保障与发布质量更新。

## 界面与可访问性

- 左侧主导航由含义不明的单字改为图标与完整中文名称。
- 调整导航宽度、层级、字号和密度，提高常见笔记本显示器上的可读性。
- 键盘焦点更加醒目，弹窗可用 `Esc` 关闭；尊重系统“减少动态效果”偏好。

## 数据保障

- 设置中可将个人资料库、项目、笔记、会话与证据快照导出为 `.ilia-workspace` 备份。
- 恢复前强制核验清单版本、文件大小、SHA-256、SQLite 完整性和数据库架构版本。
- 双数据库采用成对替换并保留失败回滚路径；损坏或不兼容的备份不会覆盖现有数据。

## 更新与发布质量

- 更新器新增完整阶段事件日志，用于诊断“退出后未重启”等更新问题。
- 发布门禁要求更新端到端按序通过检查、签名与哈希验证、安装和完成阶段。
- 发布证据汇总不再只检查文件是否存在，而会核验检索、引证、数据库、安装、离线与回滚报告的关键结果。
- 引证支持评测增加总体准确率、安全边界准确率和危险误接受阈值。

## 兼容性

- 支持从 1.1.0、1.1.1、1.1.2 或 1.1.3 直接更新。
- 核心资料库、模型与推理运行时未变化；可写数据库架构保持版本 1。

安装器未进行 Windows Authenticode 代码签名；请从项目 GitHub Release 下载，并使用随附的 `SHA256SUMS.txt` 核验完整性。
