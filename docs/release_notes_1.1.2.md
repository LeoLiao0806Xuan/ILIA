# ILIA 1.1.2 发布说明

ILIA 1.1.2 是 1.1 研究工作流的细节优化版本，不改变核心资料库、模型或推理运行时。

## 改进

- 在线和本地签名更新完成后自动重新打开 ILIA，不再要求用户手动启动。
- 启动后显示最近一次更新结果，设置页明确展示当前版本、最近发布和安装状态。
- 项目笔记在切换项目时保留尚未落盘的草稿，并区分“正在保存”“已自动保存”和“保存失败”。
- 延续 1.1.1 的版本化更新器交接、代理下载、选择性组件安装和可靠回滚机制。

## 兼容性与资料

- 支持从 1.1.0 或 1.1.1 通过“检查更新”直接升级；应用与资料库架构兼容时不强制逐补丁安装。
- 49 份规范化国际法正文、5,093 个文本块、向量与 FTS 数据保持不变。
- 继续提供完整离线安装介质和签名 `.ilia` 本地更新包。

安装器尚未进行 Windows Authenticode 代码签名；请从项目 GitHub Release 下载，并使用随附的 `SHA256SUMS.txt` 核验完整性。
