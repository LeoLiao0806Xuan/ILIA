# ILIA 1.1.0 发布说明

ILIA 1.1.0 将离线国际法问答扩展为完整的桌面研究工作流。

## 主要变化

- 新增快速查询、标准研究和深度研究三种模式，以及可取消的流式本地回答。
- 新增逐句引证校验、语义支持检查、稳定证据定位和六种引用格式。
- 新增项目、会话、证据快照、笔记、备忘录及 Markdown/HTML 安全导出。
- 支持 TXT、Markdown、HTML、DOCX 和带文本层 PDF 的受控个人资料导入。
- 新增中英文对照阅读、回答语言设置、性能档位、模型预热和空闲释放。
- 新增签名 `.ilia` 离线更新包、网络诊断、HTTP/HTTPS/SOCKS5 代理及断点续传。

## 资料与兼容性

核心数据库继续使用 1.0.1 的规范化 49份国际法资料及5,093个内容单元；`icrc-cihl-rules` 仍不进入发行数据库。1.1.0 新增的 `user.sqlite` 与 `workspace.sqlite` 位于用户应用数据目录，安装升级不会覆盖。

已完成 1.0.1→1.1.0 原目录升级测试、新安装、启动、UNCLOS 第3条检索、CPU 本地有据问答、更新回滚及卸载测试。安装器尚未进行 Authenticode 签名，Windows 可能显示“未知发布者”。
