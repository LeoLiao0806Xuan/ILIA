# ILIA 1.0.0 发布说明

ILIA 1.0.0 是面向 Windows x64 的本地国际法资料库、检索与辅助问答应用。

## 本版内容

- 50 份国际法核心文献、5,254 个可引用内容单元，以及对应的本地原始 PDF。
- 中英文文书名、条款号、判例段落号、全文和语义混合检索。
- Qwen3-4B 本地有据问答；结论可回到证据编号、页码与官方来源。
- 英文证据的本地简体中文翻译；“中文译文”选择会在浏览下一条英文证据时保持。
- 本地资料库浏览与筛选，可使用系统默认 PDF 阅读器打开原件。
- CUDA、Vulkan、CPU 自动探测与降级。
- Windows GUI 桌面程序、离线安装器和完整卸载清理。
- 应用、资料库、模型及运行时的签名更新与回滚基础设施。

## 安装

将 `setup.exe` 与全部 `.bin` 数据片放在同一目录，再运行安装器。安装介质同时携带应用、资料库、原始 PDF、模型及运行时；无须配置开发环境。

下载后请使用发行资产中的 `SHA256SUMS.txt` 核对文件完整性。

## 使用边界

ILIA 提供国际法资料检索、机器翻译与辅助解释，不构成法律意见。条约状态、保留、声明及最新法律发展应以相关官方机构的最新记录为准。
