# ILIA 1.1.3 发布说明

ILIA 1.1.3 修复在线更新期间应用提前退出、用户无法判断下载状态的问题。

## 更新体验修复

- 下载更新时 ILIA 保持打开，显示真实下载百分比、已下载 MiB、总大小和当前组件。
- 下载完成后继续显示签名、文件大小和 SHA-256 校验阶段。
- 只有全部负载校验成功后才退出桌面程序，进入很短的文件替换阶段。
- 替换完成后自动重新打开 ILIA，并继续显示最近一次更新结果。
- 更新器异常退出时不关闭现有应用，界面明确显示失败信息和可关闭提示。
- 在线和本地 `.ilia` 更新共用同一进度与故障反馈窗口。

## 兼容性

- 支持从 1.1.0、1.1.1 或 1.1.2 直接升级。
- 首次升级到 1.1.3 仍由旧版后台更新器执行；安装 1.1.3 后，后续版本更新将使用新的可视进度流程。
- 核心资料库、模型、推理运行时和可写数据库架构均未变化。

安装器尚未进行 Windows Authenticode 代码签名；请从项目 GitHub Release 下载，并使用随附的 `SHA256SUMS.txt` 核验完整性。
