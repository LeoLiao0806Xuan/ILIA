# ILIA 1.1.9 发布说明

ILIA 1.1.9 是针对 1.1.8 Windows 更新包启动故障的紧急修复，同时重新设计了本机设置页面。

## 修复

- 修复 1.1.8 更新后主窗口错误加载 `127.0.0.1:1420`、显示 `ERR_CONNECTION_REFUSED` 的问题。
- 发布脚本现在会在签名打包前强制执行 Tauri 正式构建，避免普通 Cargo 构建产物再次进入更新包。
- 完成无开发服务器启动验收，正式程序加载内置 `http://tauri.localhost/` 资源。

## 设置页面

- 按“性能与资源、更新来源与离线安装、备份与恢复”重新组织信息层级。
- 使用独立卡片、双列字段、行内状态与固定标题区，减少原先连续表单造成的拥挤和混乱。
- 明确镜像回退、代理隐私、本地签名包验证和研究数据恢复边界。

## 升级说明

- 1.1.5—1.1.7 可正常通过应用内更新升级至 1.1.9。
- 已安装故障版 1.1.8 的用户可运行 1.1.9 恢复安装程序，或使用安装目录中的更新器应用本地签名包。
- 本版仅替换应用和更新器，不重新下载模型、资料库或完整离线安装分卷。
