# ILIA 1.1.7 发布说明

ILIA 1.1.7 是 1.1 系列的 Windows 稳定性修订，集中处理 1.1.6 实际安装和使用中暴露出的进程、快捷方式、图标与教程布局问题。

## 本轮修复

- 关闭主窗口时主动取消研究任务并释放推理服务和嵌入模型。
- Windows 下将 `llama-server.exe` 放入“关闭即终止”的 Job Object；即使桌面进程被系统强制结束，也不会留下持续占用内存或显存的孤儿模型进程。
- 卸载和升级前只终止当前 ILIA 安装目录内的相关进程，不影响用户机器上的其他 llama.cpp 实例。
- 桌面快捷方式改为安装器固定维护；全新安装、覆盖安装和修复安装都会重新创建 ILIA 快捷方式。
- 为窗口、任务栏、可执行文件和网页壳明确配置同一套 ILIA 图标资源，降低升级后图标丢失或缓存回退为默认图标的概率。
- 在线更新除手动设置外会自动识别 `HTTPS_PROXY` / `ALL_PROXY` 等环境变量和 Windows 系统代理；检查与实际下载使用同一代理来源。
- 使用指南改为真正居中的定高工作区，标题、步骤栏、内容区和底部操作区各自保持稳定；在 1024×720 与高 DPI 环境下均可独立滚动。
- 安装器冒烟测试和升级矩阵增加正式安装探测保护；检测到真实 ILIA 安装时立即拒绝运行，并在测试安装中禁用快捷方式，避免 QA 再次改写用户的卸载注册和桌面入口。

## 更新与安装说明

- 1.1.5、1.1.6 均可通过已签名的应用内更新升级到 1.1.7；应用内更新只下载应用和更新器，不下载完整离线模型包。
- GitHub 不可达时可在设置中配置 HTTP/HTTPS/SOCKS5 代理、配置受信任镜像，或下载并导入 `ILIA-1.1.7-offline-update.ilia`。
- 完整离线安装器继续由一个 EXE 和三个 BIN 分卷组成；四个文件必须放在同一目录。

## 验证重点

- 前端生产构建、Rust 格式检查、Clippy 和工作区测试。
- 关闭应用后的 `llama-server.exe` 生命周期测试。
- 图标资源与安装器快捷方式定义检查。
- 安装测试生产环境保护检查。
- 更新签名、SHA-256、回滚和本地签名更新包验证。

## 已知边界

- 中国大陆正式镜像仍需确定 OSS/COS/CDN 供应商与域名；1.1.7 不会虚构或内置未经运营的镜像地址。
- Windows 安装器尚未进行 Authenticode 代码签名，系统可能显示“未知发布者”；发布包仍通过 Ed25519 更新签名及 SHA-256 清单校验。
