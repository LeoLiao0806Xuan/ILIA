# ILIA 1.0.1 发布说明

ILIA 1.0.1 是许可与离线语料整理版本。

安装器及桌面可执行文件未进行 Authenticode 签名，Windows 可能显示“未知发布者”；请使用 Release 随附的 `SHA256SUMS.txt` 核验全部四个安装文件。

## 主要变化

- 安装包改为 49 份 ILIA 规范化法律正文，不再打包来源 PDF。
- ICRC《习惯国际人道法规则》研究出版物已从发布数据库、向量和评测集排除。
- 资料库新增内置规范化正文阅读器，并保留官方来源链接与来源版页码定位。
- CUDA 三个可再分发 DLL 固定版本、来源与 SHA-256，并安装 NVIDIA EULA 和第三方条款。
- Visual C++ 运行库改用微软官方签名的 x64 Redistributable 离线安装包。
- Rust 与 npm 传递依赖许可清单纳入发布资料。

## 验证基线

- 49 份文书、5,093 个文本块、5,093 条向量和 5,093 条 FTS 记录。
- 197/197 检索评测通过，Recall@5 与 Recall@10 均为 1.0。
- Rustfmt、Clippy、Rust workspace 测试、TypeScript 和 Vite 构建通过。
- 离线安装器封装验证通过：1 个启动器、3 个数据分卷，总计 4,309,706,846 bytes。
- 本机构建机冒烟测试通过：静默安装、桌面启动、UNCLOS 第 3 条检索、CPU 本地有据问答和卸载均成功。

ILIA 提供研究辅助，不构成法律意见。规范化正文不是官方版式，正式引用应通过随附的官方来源链接核验。

## 下载与安装

请在本页底部展开 **Assets**，下载安装启动器和三个 `.bin` 数据分卷。四个文件必须放在同一目录；不要下载 GitHub 自动生成的 Source code ZIP 作为安装包。建议先使用 `SHA256SUMS.txt` 核验文件。
