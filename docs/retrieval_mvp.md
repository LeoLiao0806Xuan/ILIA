# ILIA 混合检索与证据选择

## 检索路径

1. 查询含明确文书名和条/段号时，直接走结构化精确定位。
2. 只有文书名时，返回文书元数据。
3. 自然语言查询同时运行 FTS5 和 BGE-M3 dense 向量检索。
4. FTS5 首先采用 AND 查询；严格查询为空时才回退到 OR，以兼顾精度和自然语言改写。
5. 两路各取最多 30 个候选，使用 Reciprocal Rank Fusion 合并：`score = Σ 1 / (60 + rank)`。

## 向量存储

- 模型：`gpahal/bge-m3-onnx-int8`，上游为 `BAAI/bge-m3`。
- 维度：1024。
- 格式：little-endian float32 BLOB，每条 4096 字节。
- v1.0.0 基线规模为 5,254 个内容单元；下一版 49 文书规范化发布库为 5,093 个内容单元，全部已建立 FTS5 与 BGE-M3 索引。
- 当前向量查询采用 SQLite 顺序扫描和余弦相似度；这一规模下实现简单且可复现。资料量明显扩大后再迁移到 HNSW，不提前引入额外索引依赖。

## 证据选择

最终排序结果最多返回 10 条；默认选择前 5 条作为证据，并受 12,000 字符总预算限制。每条证据保留 chunk ID、可读引证、原文、排名和选择原因，可直接提供给后续本地生成模型。

## 当前评测

v1.0.0 基线评测集共 200 题、覆盖 50 份资料，结果为 200/200。下一版排除 ICRC 习惯国际人道法规则后使用 197 题评测集，结果为 197/197，Recall@5 和 Recall@10 均为 1.0，Recall@1 为 0.9792，MRR 为 0.9865。
