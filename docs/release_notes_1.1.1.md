# ILIA 1.1.1 发布说明

ILIA 1.1.1 是 1.1 研究工作流的逻辑修复版本，不改变核心资料库、模型或推理运行时。

## 修复

- 在线更新的代理设置现在同时作用于清单、签名和组件负载下载。
- 更新器只暂存和应用版本发生变化的组件，避免重复下载或覆盖已是最新版本的数据库、模型与运行时。
- 更新前会检查 `from_version` 兼容性；不适用的跨版本更新会在退出应用前给出明确错误。
- 手动回滚按实际应用的组件和更新前版本记录恢复，不再依赖开放版本清单的推断。
- `.ilia` 离线更新包可直接从正式在线发布目录中的清单、签名和相邻负载生成。
- 修正开发环境更新助手路径，并纠正“自动重启”的误导性提示。
- 修复快速切换项目时笔记可能保存到错误项目的竞态；后端同时拒绝跨项目改写笔记。
- 研究问题、回答和证据快照改为单个 SQLite 事务保存；研究任务异常结束时也会清理活动状态。

## 数据与兼容性

核心数据库继续使用 49 份规范化国际法资料和 5,093 个内容单元。`user.sqlite`、`workspace.sqlite`、个人资料和项目研究数据在安装升级及在线更新中均保留。
