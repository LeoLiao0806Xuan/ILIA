# ILIA 1.1.6 发布说明

ILIA 1.1.6 是 1.1 系列的法律研究体验、引注可靠性、工作区交互与更新体验成品化版本。

## 本轮已实现

- 将应用壳固定在视口内，左侧主导航、项目栏、中央研究区和右侧检查器不再共享页面级滚动。
- 中央研究区独立滚动；证据、原文、审计页签独立滚动并保留各自位置。
- 快速模式直接呈现命中文书、条款、摘录、相关度和原文/引注操作，流程只显示“检索完成”。
- 原文阅读器和证据正文由纯文本 `<pre>` 改为语义化法律文书节点，识别标题、编章、条、款和正文层级。
- 原文、中文译文和双栏对照使用同一法律文书渲染器；机器译文继续明确标注非官方性质。
- 引注格式默认改为 OSCOLA，增加格式用途说明、实时预览、剪贴板回退和成功/失败提示。
- 文书类型和法律状态改用中文产品标签，机器代码不再直接暴露。
- 审计状态改为克制的线性标记，继续显示支持等级和对应证据编号。
- 项目创建加入按文书类型、法律状态、机构、主题和程序阶段划分的第一版受控词表；自定义标签单独录入。
- 删除全部系统 `alert`、`confirm` 和 `prompt` 调用；普通结果使用区域状态或轻量通知，删除、恢复、导入和安装更新使用应用内确认面板。
- 统一解析 Tauri 的结构化错误对象，优先显示 `message_zh`、`safe_message` 或 `message`，不再向用户展示 `[object Object]`。
- 教程用真实工作区结构缩略图和编号热点代替大号数字占位图。
- 更新检查改为后台触发、12 秒单源软超时、可取消等待、结果缓存并显示上次检查时间。
- 增加可配置的 HTTPS 镜像优先/GitHub 回退架构；没有配置正式镜像时不会虚构地址，所有来源仍走既有签名和 SHA-256 校验。
- 收紧生成提示：第一段直接回答，按原问题顺序处理并列事项，只在直接相关时列条件、例外和争议，避免因证据存在而扩题。

## 验证

- `npm run build`
- `cargo fmt --all -- --check`
- `cargo clippy --workspace --all-targets -- -D warnings`
- `cargo test --workspace`
- 检索评测 305/305 通过，Recall@1 为 0.9868、Recall@5 为 0.9967、Recall@10 为 1.0、MRR 为 0.9904。
- 引证支持对照集 12/12 通过，准确率和安全边界准确率均为 1.0。
- 数据库完整性、离线网络、全新安装/卸载、1.1.5→1.1.6 原地升级、更新回滚与签名拒绝均通过。
- 浏览器演示模式人工核验：固定工作区、快速检索结果、结构化原文、双语对照、教程热点。

## 边界与后续工作

- 完整 OSCOLA 元数据仍受规范化资料库现有字段限制；不能凭空补写开放签署时间、生效时间或 UNTS 编号。
- 教程目前使用与真实界面同构的标注缩略图；后续可在不改变引导逻辑的前提下替换为候选构建截图资产。
- 正式中国大陆镜像需要确定 OSS/COS/CDN 供应商、域名和已签名清单后才能启用。
- 争点清单、事实时间线、证据板、任务期限和项目级引文库保留至 1.2.0。
